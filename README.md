# PrepStack — free coding and interview-preparation website

A responsive static website built with plain HTML, CSS, and JavaScript. No framework, build step, paid service, or external dependency is required.

## Files
- `index.html` — site structure and homepage
- `styles.css` — navy/electric-blue responsive design
- `script.js` — resource search/filter, article reader dialog, quiz, mobile navigation, and demo form

## Preview locally
1. Download and extract the ZIP.
2. Open `index.html` in a modern browser.
3. For a more realistic local preview, use VS Code's Live Server extension or run a simple local server.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account at https://github.com/
2. Create a new **public** repository named `prepstack` (or another name you choose).
3. Upload `index.html`, `styles.css`, and `script.js` to the repository's root.
4. Open the repository's **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**.
6. Choose the `main` branch and `/ (root)`, then save.
7. Wait for GitHub Pages to publish the site. The URL will normally look like `https://YOUR-USERNAME.github.io/prepstack/`.

GitHub's UI can change, so follow the current labels shown in your account. A public repository is required for the free GitHub Pages workflow on GitHub Free.

## Before sharing publicly
- Replace `hello@example.com` with a real contact address you are comfortable publishing, or remove the link.
- Add your own About, Contact, Privacy Policy, and Terms/refund information as needed for the services you offer.
- The newsletter form is intentionally a demo. It does not collect or send email.
- The article reader opens content in a dialog; the initial articles are bundled in `script.js`, not individual indexable article URLs. For SEO growth, add separate static HTML article pages with unique URLs and links from the homepage.
- Add a real mailing-list provider only after reviewing its free-plan limits and privacy terms.
- For payments and digital products, use a provider available in India, check fees and eligibility, and make the delivery/refund terms clear.
- Do not copy third-party articles. Review code and explanations before publishing and add your own examples and insights.
